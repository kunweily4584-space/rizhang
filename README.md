# 日帳

極速記帳 PWA：輸入金額 → 點分類就存好。個人、驗屋代墊、農場、投資分開記，不混帳。

## 功能
- 記帳頁：數字鍵＋分類鍵，點分類即存檔，可復原
- 代墊：依公司／農場追蹤未請款、已請款、已收回，一鍵複製請款明細
- 分析：分類圓餅圖、6 個月趨勢（可切換分類）、每月預算與每日可花、儲蓄率
- 農場分類月報表（可複製）
- 投資：記錄投入／贖回，每月更新市值看損益
- 定期花費：到期前提醒、一鍵記帳
- 分類、公司、帳本名稱皆可自訂
- CSV 匯出、JSON 完整備份／還原

## 部署到 GitHub Pages
1. 新建 repository（例如 `rizhang`），把本資料夾所有檔案上傳到根目錄
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`
3. 約 1 分鐘後開啟 `https://<你的帳號>.github.io/rizhang/`
4. 手機 Chrome 開啟後選「加到主畫面」即可像 App 使用（可離線）

## 資料
資料存在手機瀏覽器本機（localStorage），不會上傳任何伺服器。
清除瀏覽器資料會一併刪除，請定期在「設定 → 匯出完整備份」。
換手機：舊手機匯出 JSON → 新手機「從備份還原」。

## 更新版本
修改檔案後，把 `sw.js` 裡的 `CACHE = 'rizhang-v1'` 改成 v2、v3…，手機重開兩次就會換新版。
